# Security Policy

## Supported Versions

We currently support the following versions of SecAgents:

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within SecAgents, please send an email to security@secagents.example.com. All security vulnerabilities will be promptly addressed.

Please do not open a public issue on GitHub for security vulnerabilities.

### Scope
- Core AI Gateway and Orchestrator
- API and Database layers
- Agent execution contexts
- The CLI tool and Installer

We ask that you provide detailed steps to reproduce the issue, and we will work with you to ensure a fix is developed and released.
