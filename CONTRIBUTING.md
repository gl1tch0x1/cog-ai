# Contributing to SecAgents

First off, thank you for considering contributing to SecAgents! It's people like you that make SecAgents such a great tool.

## Code of Conduct

This project and everyone participating in it is governed by our Code of Conduct. By participating, you are expected to uphold this code.

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug has already been reported.**
- If you can't find an open issue that describes the problem, open a new one.
- Include as much detail as possible in the issue template.

### Suggesting Enhancements

- **Check if the enhancement has already been suggested.**
- Open a new issue and describe the enhancement in detail.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code follows the existing style (we use `black` for Python, `gofmt` for Go, and `rustfmt` for Rust).

## Development Setup

See the `BOOTSTRAP.md` and `README.md` for detailed instructions on setting up your development environment.
