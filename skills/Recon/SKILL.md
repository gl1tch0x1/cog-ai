# Reconnaissance Skill

## Tools
- **SubdomainEnum**: Passive and active enumeration.
- **EndpointDiscovery**: Extracting endpoints from JS bundles.
- **PortScan**: Identifying open services and versions.
- **CorporateStructure**: Mapping parent/child orgs and acquisitions.

## Methodology
1. Find the root domain.
2. Enumerate subdomains.
3. Resolve live hosts.
4. Extract parameters and endpoints.
5. Fingerprint tech stack.
